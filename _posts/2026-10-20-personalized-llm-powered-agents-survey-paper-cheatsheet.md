## 第 2 页 / 共 4 页｜方法地图与方法族

### 四项能力地图

| 能力 | 要回答的问题 | 典型机制 | 与记忆的接口 |
| --- | --- | --- | --- |
| 用户画像建模 | 用户是谁、偏好是什么？ | 显式属性、行为归纳、角色/人设 | 生成可检索的用户状态 |
| 记忆管理 | 哪些历史值得保留和取回？ | 总结、索引、检索、更新、遗忘 | 提供当前任务相关证据 |
| 规划 | 如何把偏好转成行动策略？ | 偏好条件化计划、约束推理 | 把长期目标和偏好写入计划 |
| 动作执行 | 如何在环境中落实？ | 工具选择、参数生成、反馈修正 | 检查执行结果是否符合用户意图 |

**原文图 4：** 作者把代表方法映射到四项能力及其子类。

![原文图 4：个性化 Agent 方法分类](/assets/images/paper-cheatsheets/personalized-llm-powered-agents-survey/fig4_personalized_agent_taxonomy.png)

### 端到端闭环

$$
\text{请求}\rightarrow\text{画像/记忆}\rightarrow\text{规划}\rightarrow
\text{动作}\rightarrow\text{结果反馈}\rightarrow\text{画像与记忆更新}
$$

**阅读时分清：** Profile 是用户状态表示；Memory 是跨交互保存与检索的内容；Plan 是本次任务策略；Action 是实际环境操作。

## 第 3 页 / 共 4 页｜机制、实验与诊断

### 评估框架

| 评估维度 | 要检查什么 |
| --- | --- |
| 有效性 | 是否完成任务且符合用户目标 |
| 适应性 | 新反馈或偏好变化后是否调整 |
| 泛化性 | 能否迁移到新任务或新领域 |
| 鲁棒性 | 对歧义、噪声或冲突信号是否稳健 |
| 风险 | 是否造成隐私、安全或公平问题 |

| 基准范式 | 交互方式 | 主要测量 |
| --- | --- | --- |
| 交互式对齐 | 用户持续参与、澄清或纠正 | Agent 如何询问并适应偏好 |
| 用户替代 | Agent 在有限用户输入下代表用户行动 | 是否能正确预测并落实用户偏好 |

### 常见断点

- 画像抽取正确，记忆检索没取回。
- 记忆取回正确，规划阶段忽略偏好。
- 计划看起来符合偏好，工具参数却执行错误。
- 单轮评测通过，长期交互中偏好变化未被跟踪。
- 合成用户或 LLM 评判无法代表真实用户长期满意度。

## 第 4 页 / 共 4 页｜选型、决策与开放问题

### 按失败位置定位下一步

| 症状 | 优先检查 | 可报告指标 |
| --- | --- | --- |
| Agent 不知道用户偏好 | 画像与历史覆盖 | 属性/偏好抽取准确率 |
| 知道偏好但不记得 | 写入、索引和检索 | 必需证据召回、过期率 |
| 记得但计划不采用 | 规划中的偏好约束 | 计划偏好符合度 |
| 计划正确但操作错误 | 工具选择与参数 | 任务成功率、约束违反率 |
| 一次评测好、长期变差 | 反馈更新与时间稳定性 | 漂移适应、长期一致性 |

**决策顺序：** 用户状态错，查画像推断；状态对但证据不可见，查记忆检索；证据可见但计划不变，查规划条件化；计划符合但结果不符，查动作执行与环境反馈。
